# Mateo Aresu Coaching

Site vitrine du coaching sportif Mateo Aresu à Genève.

## Lancer en local

```bash
npm install
npm run dev
```

## Contenu

Les textes, tarifs et coordonnées correspondent à la maquette fournie. Les photos viennent d’Unsplash, libres d’utilisation, en attendant de les remplacer plus tard si besoin.

Le formulaire de contact envoie un email vers `mateo.aresu@gmail.com` via FormSubmit. Au premier envoi, un email de confirmation FormSubmit peut être nécessaire.
